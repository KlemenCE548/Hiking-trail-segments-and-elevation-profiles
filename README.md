# Hiking Trail Segments and Elevation Profiles for Fractal-Dimension Analysis of Hiking Trails

## Overview

This repository provides two complementary datasets used in the associated PLOS ONE study on the fractal-dimension analysis of hiking trails.

The datasets comprise 25 hiking trail segments and their corresponding elevation-profile observations. They were prepared to support the reproducibility and independent verification of the analyses presented in the study.

The repository contains:

- **Hiking_trails** – a spatial dataset containing the geometry and attribute information of the 25 hiking trail segments.
- **Elevation_profiles** – a CSV file containing the elevation-profile observations for all 25 trail segments.

The two datasets are linked through the common identifier `ID_Path`, which allows each trail segment to be associated with its corresponding elevation-profile observations.

### Contents of the ZIP archive

The `Hiking_trails.zip` archive contains all component files required for the `Hiking_trails` ESRI Shapefile:

- `Hiking_trails.shp` – feature geometry.
- `Hiking_trails.shx` – geometry index.
- `Hiking_trails.dbf` – attribute table.
- `Hiking_trails.prj` – coordinate reference system information.
- `Hiking_trails.cpg` – character encoding information.
- `Hiking_trails.sbn` and `Hiking_trails.sbx` – optional spatial index files.

To use the spatial dataset, download and extract `Hiking_trails.zip`. Keep all extracted shapefile component files together in the same directory.

The README files in the respective data directories provide detailed descriptions of each dataset.

### 1. Hiking_trails

The `Hiking_trails` dataset contains 25 hiking trail segments represented as polyline features. Each feature corresponds to one trail segment included in the study.

The dataset was used as the input for Script 1 of the analysis workflow.

**File format:** ESRI Shapefile

**Geometry type:** Polyline ZM

**Coordinate Reference System:** Slovenia 1996 / Slovene National Grid (D96/TM)

**EPSG code:** 3794

**Linear unit:** Meter

**Attribute fields:**

| Field | Description |
|---|---|
| `FID` | Internal feature identifier generated by the GIS software. |
| `ID_Path` | Unique identifier of the hiking trail segment. |
| `Macroregion` | Slovenian macroregion in which the trail segment is located. |
| `Difficulty` | Hiking difficulty category. |
| `Shape_Length` | Length of the trail segment (m). |

For further information, see the README file in the `data/Hiking_trails/` directory.

### 2. Elevation_profiles

The Elevation_profiles dataset contains the elevation-profile observations extracted along all 25 hiking trail segments from the 1 m Digital Terrain Model (DTM) used in the study.

All individual profiles are stored together in a single CSV file. Each row represents an individual distance–elevation observation, while the `ID_Path` field identifies the corresponding hiking trail segment.

The dataset is based on the output generated by Script 4 of the analysis workflow and was subsequently formatted for publication. It provides the elevation-profile data used in the calculation of the vertical fractal dimensions reported in the study.

**File format:** CSV

**File name:** `StackProfileResults.csv`

**Columns:**

| Column | Description |
|---|---|
| `OBJECTID` | Unique record identifier. |
| `ID_Path` | Identifier of the corresponding hiking trail segment. |
| `Distance` | Distance along the elevation profile (m). |
| `Elevation` | Elevation (m a.s.l.). |

For further information, see the README file in the `data/Elevation_profiles/` directory.

## Relationship Between the Datasets

The two datasets are connected through the `ID_Path` attribute.

In `Hiking_trails`, `ID_Path` identifies each individual hiking trail segment. In `StackProfileResults.csv`, the same identifier associates each elevation-profile observation with its corresponding trail segment.

This common identifier enables the spatial trail geometry and its elevation-profile observations to be linked for further analysis.

## Data Provenance

The hiking trail geometries were selected and prepared from hiking trail data provided by the Alpine Association of Slovenia (Planinska zveza Slovenije, PZS).

The elevation profiles were derived from the 1 m Digital Terrain Model (DTM) originating from data published by the Slovenian Environment Agency (Agencija Republike Slovenije za okolje, ARSO).

The repository contains the selected hiking trail geometries and the derived elevation-profile observations used in the study. It does not include the original DTM dataset.

The published hiking trail geometries represent the trail segments used in the analysis workflow. They should not be interpreted as a collection of original field-recorded GPS tracks.

## Terms of Use

The datasets are made publicly available to support research, independent verification, and reproducibility of the results presented in the associated study.

Users are welcome to use the datasets for research and other non-commercial academic purposes, provided that the original data sources and this repository are appropriately acknowledged.

The datasets should not be presented as original field-recorded GPS tracks or as an official representation of the complete Slovenian hiking trail network.
